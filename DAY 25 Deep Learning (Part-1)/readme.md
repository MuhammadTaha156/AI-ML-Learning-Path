[source: 24]# Unsupervised Machine Learning (Part 3): Anomaly Detection

1. Introduction to Anomaly Detection
Anomaly Detection (or Outlier Detection) is the process of identifying rare items, events, or observations which raise suspicions by differing significantly from the majority of the data.

Outlier: An extreme data point.

Anomaly: A suspicious, unusual, or unexpected data point. Often referred to as noise.

Key Use Cases:
Finance: Credit card fraud detection (e.g., detecting a sudden $90k transaction when typical transactions are $10k-$50k).

Manufacturing: Defect detection.

Medical Diagnosis: Identifying abnormal scans or vitals.

Cybersecurity: Network intrusion detection.

Bot Detection: Identifying non-human traffic.

2. Algorithms for Anomaly Detection
Since anomalies do not fit neatly into standard clusters, specific unsupervised algorithms are used to isolate them.

A. DBSCAN (Density-Based)
DBSCAN can be repurposed for anomaly detection. We previously learned it classifies points into Core, Border, and Noise.

Mechanism: Any data point that has fewer than min_samples within its ϵ-neighborhood AND is completely disconnected from any core point is considered an anomaly.

Output Label: DBSCAN labels these noise/anomaly points as -1.

B. Isolation Forest
An ensemble algorithm built specifically for anomaly detection. It works on the premise that anomalies are "few and different," making them easier to isolate than normal points.

Mechanism:

It builds multiple random Decision Trees (Isolation Trees).

It randomly splits features until every single point is isolated into its own leaf node.

Because anomalies are far away from dense, normal data (they live in sparse space), they require fewer splits to isolate.

Path Length (PL): The number of splits (edges) from the root node to the leaf node holding the sample.

PL↓⟹ Outlier ↑ (Short path = likely anomaly)

PL↑⟹ Normal ↑ (Long path = deep inside a dense cluster)

Anomaly Score (AS): The average path length across all the trees is used to calculate the score.

# Deep Learning (Part 1)

## 1. Introduction to Deep Learning
Deep Learning (DL) is a subset of Machine Learning (ML), which in turn is a subset of Artificial Intelligence (AI). Generative AI (GenAI) sits inside Deep Learning.

While ML relies on algorithms to find patterns in structured data, DL uses **Neural Networks** (inspired by the human brain) to learn from vast amounts of data. 

**Core Applications of DL:**
1.  **NLP (Natural Language Processing):** Processing text (e.g., LLMs).
2.  **CV (Computer Vision):** Processing images/videos (e.g., self-driving cars).

---

## 2. Machine Learning vs. Deep Learning

| Feature | Machine Learning (ML) | Deep Learning (DL) |
| :--- | :--- | :--- |
| **Data Type** | Structured data (Excel, CSV) | Unstructured data (text, images, photos/videos, audio) |
| **Task Complexity** | Simple tasks | Big data $\rightarrow$ complex tasks |
| **Interpretability** | More interpretable | Less interpretable (often considered a "Black Box") |
| **Training Time** | Shorter training time ($\downarrow$) | Longer training time ($\uparrow$) |
| **Hardware Needed** | CPU, standard PC, small servers | High computation power $\uparrow$ (GPUs, TPUs) |

---

## 3. Neural Networks Overview
Neural Networks (Artificial Neural Networks - ANN) are networks of interconnected **neurons (nodes)** organized in layers.

### Types of ANNs:
*   **FNN:** Feedforward Neural Network
*   **RNN:** Recurrent Neural Network
*   **CNN:** Convolutional Neural Network

### Neural Network Architecture:
A standard neural network consists of:
1.  **Input Layer:** Receives the initial features (e.g., height, weight, age $\rightarrow$ $x_1, x_2, x_3$).
2.  **Hidden Layers:** Intermediate layers where computations occur.
3.  **Output Layer:** Produces the final prediction.

*Note: The core components of training a Neural Network include the Input/Output Layers, Weights, Bias, Activation Function, Forward/Backward Propagation, Loss Function, and Optimizers.*

---

## 4. The Perceptron
The Perceptron (developed in the 1950s) is the simplest form of a neural network. It consists of a **single neuron** (single-layered NN) and is primarily used for binary classification.

### Components of a Perceptron:
1.  **Input ($x_1, x_2, ..., x_n$):** The features from the dataset.
2.  **Weight ($w_1, w_2, ..., w_n$):** Represents the contribution/importance of each input to the final output.
    *   *Example:* If predicting a final grade, mid-sem ($x_1$) might have weight 0.3, end-sem ($x_2$) weight 0.4, and class tests ($x_3$) weight 0.3.
3.  **Bias ($b$ or $\theta_0$):** A constant term added to the equation to shift the activation function.

### How a Perceptron Works:
**Step 1: Calculate the Weighted Sum (Dot Product / Net Input)**
The perceptron takes the inputs, multiplies them by their respective weights, and adds the bias. This is identical to the equation for Linear Regression (LR).
$$z = \sum_{i=1}^{n} x_i \cdot w_i + b$$
*OR represented as a hypothesis function:* $\hat{y} = h_\theta(x) = \sum \theta_i x_i + \theta_0$

**Step 2: Apply the Activation Function**
The result ($z$) is then passed through an **Activation Function**. This step introduces **non-linearity**, allowing the model to solve complex problems that cannot be separated by a simple straight line.

## 5. Activation Functions
The Activation Function is applied to the weighted sum ($z$) inside a neuron. Its primary purpose is to introduce **non-linearity** into the output, allowing the neural network to learn and model complex, non-linear relationships.

### Common Types of Activation Functions:
1.  **Step Function:**
    The earliest activation function used in the original Perceptron. It is non-differentiable, making it unsuitable for modern gradient-descent-based training.
    *   If $x \ge 0 \implies 	ext{Output } 1$
    *   If $x < 0 \implies 	ext{Output } 0$
2.  **Sigmoid:**
    Squashes the output between $0$ and $1$. It is often used as the **last step of a Neural Network for Binary Classification**.
    $$f(x) = rac{1}{1 + e^{-x}}$$
3.  **Tanh (Hyperbolic Tangent):**
    Squashes the output between $-1$ and $1$. Generally preferred over Sigmoid in hidden layers because it centers data around zero.
    $$f(x) = 	anh(x) = rac{e^x - e^{-x}}{e^x + e^{-x}}$$
4.  **ReLU (Rectified Linear Unit):**
    The most popular activation function for hidden layers due to its computational efficiency and ability to mitigate the vanishing gradient problem.
    $$f(x) = \max(0, x)$$
5.  **Softmax:** Used in the output layer for multi-class classification.
6.  **Linear:** No activation applied (used in the output layer for regression).

## 6. Multi-layer Neural Networks (Deep Learning)
A Perceptron is just a single neuron. True "Deep Learning" occurs when we link many neurons together across multiple layers.

*   **Input Layer:** Receives the raw data.
*   **Multiple Hidden Layers:** The intermediate layers that do the heavy lifting. The number of hidden layers defines the **Depth** of the network.
*   **Output Layer:**
    *   For Regression or Binary Classification $
ightarrow$ Usually $1$ neuron.
    *   For Multi-class Classification $
ightarrow$ $n$ neurons (one for each class).

## 7. How a Neural Network Learns
The learning process of a neural network involves passing data forward, measuring the error, and passing that error backward to adjust the weights.

### Step 1: Forward Propagation
Data flows in one direction: from the Input Layer $
ightarrow$ through Hidden Layers $
ightarrow$ to the Output Layer.
*   Inputs are multiplied by weights.
*   Bias is added.
*   The weighted sum is passed through the activation function.
*   This results in a final prediction ($\hat{y}$).

### Step 2: Calculate Loss
We compare the prediction ($\hat{y}$) against the actual true value ($y$).
*   If $\hat{y} 
e y$, we have a **Loss**.
*   This is quantified using a **Loss Function** (e.g., Mean Squared Error - MSE).

### Step 3: Backward Propagation (Backprop)
The goal is to **minimize this loss**. To do this, the network works backward from the output layer to the input layer.
*   It calculates how much each weight contributed to the error (using calculus/chain rule).
*   It uses **Optimizers** (algorithms/techniques like **Gradient Descent**) to determine how to change the weights.
*   Finally, it **adjusts/updates the weights** to make the network more accurate for the next pass.
